# Netflix Data Analysis in Power BI

## Overview
This project analyzes Netflix movies and TV shows using Power BI.
Key metrics include IMDb ratings, votes, runtime, and age certifications.

## Dashboards
- Content Overview (Movies vs TV Shows, Runtime distribution)
- Ratings Dashboard (Top 10 titles, Avg IMDb score by type)
- Popularity Dashboard (Votes vs Score correlation)
- Audience Segmentation (Age certification trends)

## Files
- `Netflix Movies and Shows Analysis.pbix` → Power BI dashboards
- `Netflix TV Shows and Movies.xlsx' → dataset
- 'Dashboard.png' → A quick data visualization
- `README.md` → project documentation

## Insights
- Movies generally have Lesser Average IMDb scores than TV shows.
- Age certification strongly correlates with runtime.
- Shown top 10 titles by imdb score
